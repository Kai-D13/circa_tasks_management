🧠 2. RBAC – Thiết kế lại theo yêu cầu của bạn
Roles (fixed)

Permission Matrix (rõ ràng để implement RLS)
Action	Admin	Store Manager	Staff
View all tasks	✅	❌	❌
View store tasks	✅	✅	❌
View own tasks	✅	✅	✅
Create task	✅	❌	❌
Assign task	✅	✅ (within store)	❌
Submit task	❌	❌	✅
🔥 Supabase RLS (quan trọng)

Ví dụ policy:

-- Staff chỉ thấy task của mình
user_id = auth.uid()

-- Store manager thấy task cùng store
store_id IN (
  SELECT store_id FROM users WHERE id = auth.uid()
)

-- Admin thấy tất cả
role = 'admin'

👉 Đây là core security của hệ bạn
