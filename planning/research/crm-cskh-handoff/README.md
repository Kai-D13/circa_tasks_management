# Gói đầu vào — Module Chăm sóc khách hàng Circa (duocsi.circa.vn)

> Đây là tài liệu nghiên cứu, **chưa phải spec được duyệt**. Thứ tự hiện hành: quyết định stakeholder trong `DECISIONS.md` và `planning/CONTRACT.md` → tài liệu gốc → câu hỏi mở → SPEC nháp → mockup. Xem `planning/STATE.md` để biết giai đoạn hiện tại.

| File | Dành cho | Mục đích |
|---|---|---|
| `SPEC.md` | PM + Dev | Bản nháp BA để phản biện, chưa là source of truth |
| `OPEN_QUESTIONS.md` | Stakeholder | Q-01…Q-32 cần xác nhận, mỗi câu có mặc định đề xuất |
| `DECISIONS.md` | Mọi người | Ghi quyết định stakeholder đã chốt; cập nhật CONTRACT theo đó |
| `CLAUDE_CODE_PROMPTS.md` | Bạn | Prompt từng bước để giao việc cho Claude Code |
| `mockups/` | Claude Code | 4 ảnh mockup gốc của stakeholder |
| `00_SOURCE_stakeholder_raw.md` | Tham khảo | Nội dung CMS.docx gốc, không chỉnh sửa |

Cách dùng: đọc tại chỗ trong `planning/research/crm-cskh-handoff/`; ghi điều đã chốt vào `DECISIONS.md` rồi cập nhật `planning/CONTRACT.md`. Sau khi chốt câu hỏi 🔴 mới viết `planning/SPEC.md` và kế hoạch triển khai.
